# Contributing

Contributions are welcome when they improve reliability, accessibility, privacy or browser compatibility without introducing paid API requirements.

Please keep changes focused and test the affected tool with representative files before opening a pull request. Do not add server-side file uploads, tracking/telemetry, or third-party code without documenting the reason and license.

For bug reports, include the tool name, browser/device, sample format/size (without private files), the exact error message and steps to reproduce.
